# Maid Seeds
# 女仆种子

[![Available on GitHub](https://wsrv.nl/?url=https%3A%2F%2Fcdn.jsdelivr.net%2Fnpm%2F%40intergrav%2Fdevins-badges%403%2Fassets%2Fcozy%2Favailable%2Fgithub_vector.svg&n=-1) ](https://github.com/Steven23334/Maid_Seeds)

This is an addon for the **Touhou Little Maid** mod. It adds a new crop that grows into a maid, letting you "plant" maids and harvest them like any other crop.

## 📦 New Content

- **Maid Seed**  
  A rare seed that can be planted on farmland. It grows through 8 stages and eventually matures into a maid.

- **Maid Crop**  
  A special crop block. While growing, the maid inside slowly rises out of the soil. When fully grown, breaking the crop spawns the maid as an entity.

- **Maid Photo**  
  A photo item generated by the crop, containing the maid's model data. Can be used to store or transfer a maid's appearance.

## 🎯 Purpose

- Adds a new, fun way to obtain maids without using a spawn egg or a photo.
- Lets players "farm" maids with random models, similar to how vanilla crops work.
- Provides more options for modpack authors to create quest rewards or crafting recipes.
- Adds more fun and variety to maid gameplay.

## 🔧 Installation

1. Make sure the **Touhou Little Maid** mod is installed.
2. Place the `.jar` file of this mod into the `.minecraft/mods` folder.
3. Launch the game.

## ⚠️ Requirements

- **Minecraft Versions**: 1.21.1
- **Required Mod**: [Touhou Little Maid](https://modrinth.com/project/R0bDWFAW),[Steven's Mod API](https://modrinth.com/project/ZfeSnlBx)

## ⚠️ Compatibility Notes

This mod adds a new crop and item. It does not modify any vanilla or TLM behavior, so it should be compatible with most addons.

If you use other mods that add custom crops or change farmland behavior, make sure they do not conflict with the `maid_seeds:maid_crop` block.

# 女仆种子

[![可在 GitHub 上获取](https://wsrv.nl/?url=https%3A%2F%2Fcdn.jsdelivr.net%2Fnpm%2F%40intergrav%2Fdevins-badges%403%2Fassets%2Fcozy%2Favailable%2Fgithub_vector.svg&n=-1) ](https://github.com/Steven23334/Maid_Seeds)

这是一个为 **车万女仆 (Touhou Little Maid)** 模组开发的拓展，添加了一种可以种出女仆的作物，让你像种小麦一样“种”女仆。

## 📦 新增内容

- **女仆种子 (Maid Seed)**  
  一种稀有的种子，可以种在耕地上，经过 8 个生长阶段后成熟。

- **女仆作物 (Maid Crop)**  
  一种特殊的作物方块。生长过程中，女仆会从土里慢慢冒出来。完全成熟后，破坏作物会直接生成对应的女仆实体。

- **女仆照片 (Maid Photo)**  
  由作物生成的照片物品，包含女仆的模型数据，可用于保存或转移女仆的外观。

## 🎯 模组用途

- 提供一种不用刷怪蛋、不用照片就能获得女仆的新方式。
- 让玩家可以像种原版作物一样“种”出随机模型的女仆。
- 为整合包作者提供更多任务奖励或合成配方的选择。
- 增加女仆玩法的趣味性和多样性。

## 🔧 安装方法

1. 确保已安装 **车万女仆 (Touhou Little Maid)** 模组。
2. 将本模组的 `.jar` 文件放入 `.minecraft/mods` 文件夹。
3. 启动游戏即可。

## ⚠️ 前置要求

- **Minecraft 版本**：1.21.1
- **必需模组**：- **Required Mod**: [车万女仆 (Touhou Little Maid)](https://modrinth.com/project/R0bDWFAW),[Steven's Mod API](https://modrinth.com/project/ZfeSnlBx)

## ⚠️ 兼容性提示

本模组只新增作物和物品，不修改原版或 TLM 的既有行为，因此与大多数拓展兼容。

如果你同时使用其他添加自定义作物、或修改耕地行为的模组，请确认它们不会与 `maid_seeds:maid_crop` 方块冲突。
